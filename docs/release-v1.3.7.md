## Added
- Bass Module and Surround Speakers connection diagnostics (wired/wireless), plus accessory pairing status.
- Soundbar Audio Mode and Firmware Update Status diagnostic sensors.
- Optical Auto-Wake switch.
- Experimental accessory pairing start and stop actions.

## Improved
- Accessory pairing requires explicit confirmation and includes capability checks, serialized requests, and reconnection safeguards.
- Expanded offline test coverage for accessory controls and soundbar diagnostics.

## Notes
- Accessory pairing is experimental and has not been validated on a physical soundbar. Starting discovery may interrupt existing wireless surround speakers.
- No soundbar settings are changed automatically by this update.
